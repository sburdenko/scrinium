# Feature matrix

This page shows which features each Kestrel Analytics plan includes.

| Feature | Free | Starter | Team | Business |
|---|---|---|---|---|
| Dashboards | 1 | 5 | 25 | unlimited |
| Custom reports | not included | included | included | included |
| Email alerts | not included | not included | included | included |
| Audit log | not included | not included | included | included |
| API access | read only | read and write | read and write | read and write |
| Single sign-on (SSO) | not included | not included | not included | included |
| White-label reports | not included | not included | not included | included |
| Data export (CSV) | included | included | included | included |
| Priority support | not included | not included | not included | included |

## Notes

Single sign-on supports SAML 2.0 and OpenID Connect and is available on the Business plan only.

White-label reports remove the Kestrel logo from exported and scheduled reports and use the customer's own logo and colours.

The audit log records who changed which setting and keeps its entries for the same period as the plan's data retention.

Email alerts notify a team member when a metric crosses a threshold or when traffic drops unexpectedly. They are available on Team and Business.
