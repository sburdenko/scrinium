Brightmoor Sync Release Notes

4.2 (8 September 2026)

  • The default sync interval is now 15 minutes instead of 30 minutes.
  • New command brightmoor logs --since shows the log of a recent period, for example --since 2h.
  • Fixed: the agent no longer stops when a watched folder is on a network drive that briefly disconnects.

4.1 (2 June 2026)

  • The --legacy-sync flag has been removed. Workspaces that still used it move to the regular sync engine automatically.
  • Conflict copies are now kept for 30 days instead of 7 days.

4.0 (16 March 2026)

  • Node.js 18 and 20 are no longer supported; the agent needs Node.js 22 or later.
  • The configuration file is now TOML: agent.yaml is replaced by agent.toml, and brightmoor config migrate converts an old file.
